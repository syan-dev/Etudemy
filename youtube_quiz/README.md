# YouTube Quiz Extension

## Overview
This project is a browser extension that generates and displays quiz questions based on a YouTube video.  
It is currently under development and works for a specific video with a predefined question set and timestamps.

## How It Works
- The extension loads a YouTube video and displays related quiz questions beside or below the player.
- Questions are tied to specific timestamps in the video.
- When the video reaches a given time, the corresponding question appears.
- The current version is fixed to work with one test video and a predefined dataset while core features are being stabilized.

## Development Notes
- The structure follows a modular setup with scripts handling UI rendering, timestamp events, and quiz logic.
- Future updates will include:
  - Support for dynamic video and question loading.
  - Synchronization between multiple video sources.
  - UI and performance optimization.

## Status
- Prototype version  
- Currently supports only one specific video and quiz set  
- Features and dynamic data loading are still being developed
