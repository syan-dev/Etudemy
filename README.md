# Etudemy

Learn from YouTube videos proactively with AI-generated questions.

![Etudemy Quiz](images/quiz.png)

### Installation

To use Etudemy, follow these steps:

* Open Google Chrome and open chrome://extensions/
* Enable `Developer mode` using the toggle switch in the top right corner.
* Follow instructions from  [Get started with built-in AI](https://developer.chrome.com/docs/ai/get-started/) to enable Google Chrome Built-in Generative AI features.
* Click on the `Load unpacked` button and select the `extension/` directory from this repository.
* The Etudemy extension should now be installed and visible in your browser's toolbar.

### Usage

Open a YouTube video, click the Etudemy extension icon in the toolbar, and enjoy learning with AI-generated questions!
