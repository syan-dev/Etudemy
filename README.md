# Etudemy

Learn from YouTube videos proactively with AI-generated questions.

![Etudemy Quiz](images/quiz.png)

### Installation

To use Etudemy, follow these steps:

* Open Google Chrome and open chrome://extensions/
* Enable `Developer mode` using the toggle switch in the top right corner.
* Follow instructions from  [Get started with built-in AI](https://developer.chrome.com/docs/ai/get-started/) to enable Google Chrome Built-in Generative AI features.
* Click on the `Load unpacked` button and select the `extension/` directory from this repository.
* The Etudemy extension should now be installed and visible in your browser's toolbar.


### Usage

Open a YouTube video, click the Etudemy extension icon in the toolbar, choose the difficulty level, and start answering the AI-generated questions!

![Start the quiz](images/setting.png)

After some duration, Etudemy will generate questions based on the video content.

![Answer questions](images/quiz.png)

You can stop the quiz at any time by clicking the `Stop Quiz` button. After completing the quiz, you can review your answers and see explanations for each question.


![Quiz Results](images/result.png)

You can also write down your own notes related to the video content.


![Quiz Notes](images/notes.png)
